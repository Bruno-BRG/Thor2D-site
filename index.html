Get Thor2D v0.11 Read the docs

Start in 30 seconds

One import. Typed callbacks. No engine editor standing between you and the game loop.

package game

import thor2d "thor2d"

draw :: proc(ctx: ^thor2d.Context) {
    thor2d.Clear_Screen(ctx)
    thor2d.Draw_Circle(ctx, thor2d.Vec2{100, 100}, 32, thor2d.Green)
}

main :: proc() {
    thor2d.Run(thor2d.Default_Config(), thor2d.Game{Draw = draw})
}
$ git clone https://github.com/Bruno-BRG/Thor2D.git
$ cd Thor2D && ./build.sh deps
$ ./build.sh hello

Why Thor2D

⚡Simple runtime

Load, Fixed_Update, Update, Draw and typed events — a tiny explicit loop you learn in minutes.

🧱Real physics

Fixed-step Box2D 3.x worlds, 7 joint kinds, raycasts, sensors and event-driven collision callbacks.

🔊Spatial audio

miniaudio engine: static/stream/queue sources, buses, effects, doppler, listener orientation, mic capture.

🤖Headless mode

Run the same game logic with no window or GPU — deterministic sims, tests and servers.

📦Packaging

Signed .thor packages with SHA-256 manifests. Save dir → project → archive lookup.

📖Complete wiki

Every module documented with semantics, examples and capability rules — written for builders.
